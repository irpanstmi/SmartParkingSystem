# Smart Parking System

A desktop-based parking management application built with Java Swing to simplify vehicle parking operations.

## Features

- **Vehicle Entry:** Register vehicles entering the parking area.
- **Vehicle Exit:** Process vehicle departures and calculate parking fees.
- **Parking Slot Monitoring:** Display available and occupied parking slots.
- **Vehicle Search:** Search parking records using vehicle plate numbers.
- **Parking History:** View vehicle entry and exit records.
- **Parking Fee Calculation:** Calculate parking fees based on parking duration.

## Technologies Used

- Java
- Java Swing
- Object-Oriented Programming (OOP)

## Installation and Usage

1. Install a compatible Java Development Kit (JDK).
2. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Smart-Parking-System.git
   ```

3. Open the project folder.
4. Compile the Java source file:

   ```bash
   javac SmartParkingSystem.java
   ```

5. Run the application:

   ```bash
   java SmartParkingSystem
   ```

## Project Purpose

This project was developed as a learning and portfolio project to practice Java programming, GUI development, and basic parking management operations.
